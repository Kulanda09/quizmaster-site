# QuizMaster

Полный исходный код сайта тестов и викторин. Это не набор отдельных HTML-страниц: интерфейс собран на React (TanStack Start + Vite + TypeScript). Стили находятся в `src/styles.css` (Tailwind CSS v4). Вся логика тестов, аккаунтов, своих квизов, кода входа и ИИ — в `src/`.

Папка `node_modules` в архив не входит: она весит сотни мегабайт и ставится командой ниже из `package-lock.json`. Версии зависимостей не сокращены и не заменены заглушками.

## Что внутри

| Папка | Содержимое |
|---|---|
| `src/routes` | Страницы: главная, тест, баттл, вход, кабинет, Pro, создание квиза, игра по коду, результаты |
| `src/styles.css` | Дизайн |
| `src/lib` | Логика квизов, авторизации, базы |
| `src/components` | Оболочка, форма квиза, 3D-сцена, кнопка «жіберу» |
| `public` | Иконки, баннеры и картинки |
| `migrations` | Таблицы базы |
| `package.json`, `package-lock.json` | Полный список зависимостей |

## Требования

- Node.js 20 или новее
- npm

## Запуск на своём компьютере

```bash
npm ci
npm run dev
```

Сайт откроется на [http://localhost:8080](http://localhost:8080).

Без переменной `DATABASE_URL` данные пишутся во встроенную базу PGLite (файл рядом с проектом). Для публикации в интернете задайте Postgres, например Neon:

```bash
DATABASE_URL=postgresql://user:password@host/db npm run build
```

Сборка:

```bash
npm run build
npm run preview
```

## ИИ-квиз

Генерация вопросов вызывает xAI. Без ключа остальной сайт работает, а кнопка ИИ отвечает «ЖИ кілті бапталмаған».

```bash
XAI_API_KEY=ваш_ключ npm run dev
```
